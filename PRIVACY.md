# Privacy policy

Quran (`io.zakkyhidayat.quran`) does not collect, sell, or share personal data. It has no account, no ads, no analytics,
no crash reporting, and no third-party tracking SDKs.

## Data on your device

Bookmarks, your last read position, and your settings are stored only on your device. You can export them to a JSON
file you choose (Settings → Backup), for example on the device or in a cloud storage app; the app does not read that file
unless you restore from it or turn on auto backup for it.

Android may include the app's data in your device's own backup to your Google account, as for any app that allows
backup. This is controlled by your device settings, not by the app.

## Network use

The app connects to the internet only to:

- download translations you add, and the list of available translations, from the project's GitHub Releases;
- check GitHub Releases for a newer version of the app (GitHub build only, at most once a day, or when you tap
  Settings → Version).

These requests go to GitHub (`github.com`, `api.github.com`, and GitHub's download servers). Like any web server, GitHub
receives your IP address and basic request information; see GitHub's privacy statement. The app sends no identifiers of
its own.

## Permissions

| Permission | Why |
|------------|-----|
| Internet | Download translations and check for app updates, as described above |
| Install unknown apps (GitHub build only, asked when you update) | Install an app update you downloaded from GitHub Releases |
